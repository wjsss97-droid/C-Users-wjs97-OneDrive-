# 제이에이치테크 · 기업애로 원스톱 에이전트 참여 신청 (공모사업 기획)

- 일자: 2026-10-14
- 요청: 대표이사 (제이에이치테크 기술·경영 총괄 PM)
- 작성: 비서실
- 상태: 제출본 초안 완료, 빨간 글씨 항목 기재 후 제출

## 개요

- 사업: 「2026년 구미 경제정책지원센터 설치·운영사업」 기업애로(위기대응) 원스톱 에이전트 (구미시·구미전자정보기술원)
- 신청 분야: 공모사업 기획 (과제 발굴, 과제 기획, 사업계획서 작성)
- 희망 전문가: 전종원 ((주)건일산업 대표이사), 대표이사가 직접 기술지도 수행
- 기술지도 목표: 웨이퍼 콤보(PCTFE) 시제품 성과를 국가 R&D로 연결
  - 1순위 목표 사업: 2027년도 중기부 중소기업기술혁신개발사업(소재·부품·장비 분야)
  - 세부 과제(안): 반도체 세정·이송장비용 ±5㎛급 고정밀 PCTFE 웨이퍼 콤보 모듈 및 저변형 초정밀 가공기술 개발
- 추진일정: 현장 방문 10회(회당 2시간 이상), 2026.11.3 ~ 11.27 (25일)

## 제출 전 기재·확인 (문서의 빨간 글씨)

1. 2024년 매출액(총·국내·해외)과 고용인원
2. 홈페이지 (없으면 "없음")
3. 신청일·제출일의 '일' (서식에는 2026년 10월까지만 기재)
4. 대표자 직인

## 작성 시 판단·가정 (확인 권장)

- 산업분야는 '기계'로 체크 (반도체 장비용 정밀 가공부품)
- 법인등록번호는 '해당 없음(개인사업자)' (사업자번호 513-17-… 기준)
- 공장 소재지·전화는 본사와 동일하게 기재
- 2025년 매출 1,677백만원, 해외매출 0, 고용 11명, 2026년 예상 1,700백만원은 참고2(2026.5) 기준
- 방문 10회·사업기간 11월까지는 보도 기준. 공고문과 담당자 확인 후 일정 조정
- 접수 마감이 자료마다 9.30 / 10.30으로 달라 제출 가능 여부 확인 필요 (구미전자정보기술원 구미정책기획연구소 054-479-2266, 2267)

## 유의사항

- 2025년 대구·경북 시장대응형-소부장 R&D는 매출 20억원 이상이 신청 요건이었음. 2025년 매출 16.8억원이라 2027년 요건이 같으면 해당 내역사업은 어려움 → 계획서에 대안(구매조건부신제품개발 등) 명시함
- 전문가가 기업과 기존 자문 관계가 있는 경우 제한 규정이 있는지 공고문에서 확인
- 참고1·2의 시장규모 원화 환산("2025년 약 1,655조 원(US$125.5B)")은 단위 오류(약 170조 원 수준). 이번 계획서에는 최신 SEMI 전망(2026.7: 2026년 1,659억 달러)으로 기재
